# Riot Fix

Утилита для Windows, которая снимает исключения Riot в Zapret и проверяет HTTPS-подключение напрямую. Во время проверок системный прокси не используется.

## Запуск

- `riot-fix.exe` запрашивает права администратора, ищет установки Zapret на доступных локальных и съёмных дисках и удаляет отдельные строки `riotgames.com` и `riotcdn.net` из каждого найденного `lists\list-exclude.txt`. Рядом с изменёнными файлами остаются резервные копии.
- Для каждой копии Zapret утилита включает Game Filter (TCP и UDP) и Auto-Update Check, скачивает актуальный IPSet у Flowseal и загружает его в IPSet Filter. При ошибке загрузки существующий IPSet сохраняется.
- После обработки Zapret утилита проверяет адреса Riot и закрепляет в системном `hosts` только адреса, прошедшие три HTTPS-проверки. Если DNS-адреса работают стабильно, закрепление не требуется. Остальные записи `hosts` сохраняются.
- `riot-fix.exe --check` проверяет API конфигурации Riot. Этот режим не требует прав администратора и не меняет файлы.
- `riot-fix.exe --dry-run` проверяет список установок и предлагает изменения для текущего состояния сети. Он не применяет изменения Zapret, поэтому сетевой результат может отличаться от обычного запуска.
- `--no-pause` позволяет завершить обычный запуск без ожидания Enter.

После применения исправлений перезапусти Riot Client. Проверка API конфигурации подтверждает доступность этого API. Вход в аккаунт и игровой трафик проверяются в клиенте.

## Сборка

Требуются Windows, Rust с поддержкой edition 2024 и инструменты для целевого набора MSVC. В работе утилита использует системные `curl.exe` и Windows PowerShell.

```powershell
cargo test --locked
cargo build --release --locked
.\target\release\riot-fix.exe --check
```

## Исходники

- `src/main.rs` управляет режимами запуска и порядком операций.
- `src/zapret.rs` ищет установки и обновляет списки исключений.
- `src/network.rs` получает DNS-адреса и проверяет доступность по HTTPS.
- `src/hosts.rs` обновляет управляемые строки в системном `hosts`.
- `src/windows.rs` отвечает за повышение прав и очистку кеша DNS.

Чтобы откатить изменения, закрой утилиту и восстанови нужный файл из резервной копии рядом с ним. Для системного `hosts` нужны права администратора.

Обход дисков может занять некоторое время. Поиск пропускает недоступные каталоги и точки повторной обработки Windows. При запуске из уже повышенной консоли код `0` означает успешное завершение, `1` означает системную ошибку, а `2` означает, что часть сетевых проверок не прошла. Если Windows открыла отдельный процесс через UAC, исходная команда сообщает, удалось ли запустить этот процесс.
