Riot Fix проверяет прямое подключение к серверам Riot на Windows. Утилита пригодится, если Riot Client или VALORANT зависает при подключении, а на компьютере установлен Zapret от Flowseal.

## Запуск

1. Запусти `riot-fix.exe` и подтверди запрос прав администратора.
2. Дождись окончания проверки. Программа ищет установки Zapret и выбирает самую новую доступную версию.
3. Полностью закрой Riot Client и открой его снова.

| Команда | Действие |
| --- | --- |
| `riot-fix.exe` | Применяет настройки Zapret и проверяет адреса Riot. |
| `riot-fix.exe --check` | Проверяет HTTPS к API конфигурации Riot без прав администратора. |
| `riot-fix.exe --dry-run` | Ищет копии Zapret и проверяет сеть без записи файлов. |
| `riot-fix.exe --no-pause` | Применяет исправления и выходит без ожидания Enter. |

Успешный `--check` подтверждает доступность API конфигурации. Вход в аккаунт и запуск игры проверяй в клиенте.

## Что меняется

- В выбранной копии Zapret утилита убирает строки `riotgames.com` и `riotcdn.net` из `lists/list-exclude.txt`.
- Включает Game Filter для TCP и UDP и включает Auto-Update Check. Скачивает [список IPSet от Flowseal](https://github.com/Flowseal/zapret-discord-youtube/blob/main/.service/ipset-service.txt) и загружает его в IPSet Filter. При ошибке скачивания сохраняет текущий список.
- Проверяет адреса Riot по HTTPS без системного прокси. Если нужен запасной адрес, добавляет его в `hosts` после трёх успешных проверок. Ручные записи сохраняются.

При замене существующего файла утилита сохраняет копию рядом с ним. Для отката восстанови нужный файл из этой копии. Для системного `hosts` понадобятся права администратора.

## Сборка из исходников

В папке с `Cargo.toml` выполни команды ниже. Для сборки нужны Rust с поддержкой edition 2024 и инструменты MSVC. Для работы утилита использует системные `curl.exe` и Windows PowerShell.

```powershell
cargo test --locked
cargo build --release --locked
.\target\release\riot-fix.exe --check
```

Код завершения `0` означает успех, `1` означает системную ошибку, `2` означает, что часть сетевых проверок не прошла. При повышении прав через UAC исходный процесс сообщает результат запуска, а итог работы выводит новое окно.

Поиск пропускает Windows, AppData и кеши. Он проверяет корни дисков и основные пользовательские папки до глубины 4, с ограничением 4 секунды или 15 000 каталогов на диск. Самая новая версия выбирается среди найденных копий.
